# MCP Client Lab

This lab teaches you how to build Model Context Protocol (MCP) clients.

## What You'll Learn

- STDIO transport connections
- Tool invocation patterns
- Resource reading via URIs
- Prompt template usage

## Getting Started

Run from `MCP Labs/`:

```powershell
python 08_custom_mcp_client.py servers/lab_server.py
```

Then try: `tools`, `call`, `resources`, `read`, `prompts`, `prompt`, `quit`.
